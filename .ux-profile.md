# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Notion <!-- Linear | Stripe | Apple Native | Raycast | Notion | Custom -->
- **Notes:** "Paper" direction, picked from four concepts. Warm paper ground (`paper` #f7f5f0), ink text and borders (`ink` #121212), Fraunces for display numerals and headings, Inter for UI text. Cards are white tiles with a 2px ink border. Primary actions are solid ink pills; secondary actions are 2px ink-outlined pills. One highlight colour (`mark` #f2c94c) shows the selection and who is answering. `good`/`bad` are for results only. Tokens live in `client/tailwind.config.js`; component classes (`btn-*`, `panel`, `field`, `eyebrow`, `rule`) live in `client/src/index.css`. Mobile-first: max-w-md column.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Colour beyond the Paper tokens. No new accent hues.

## Accessibility target

- **Level:** WCAG 2.1 AA <!-- WCAG 2.1 AAA | WCAG 2.1 AA -->
- **Contrast:** Body text at least 4.5:1, large text and UI boundaries at least 3:1. `muted` #5c5a55 on `paper` is about 6.5:1. Never put text on `line` #d9d4c8.
- **Touch / focus:** 44×44px minimum targets; 48px tall buttons by default. Global `:focus-visible` outline is a 2px ink ring with offset. Respects `prefers-reduced-motion`.

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct <!-- Utilitarian & Minimal | Warm & Humancentric | Opinionated & Direct -->
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Short, punchy, verb-first: "Buzz in", "Play ranked", "Join a room". Headline states are full sentences in the display face ("Make 24.", "Your turn. Make 24."). Errors say how to recover and never blame the player.

## Icon library

- **Library:** Project SVG <!-- Lucide | Heroicons | Phosphor | Tabler | Radix Icons | Remix Icon | Project SVG | None -->
- **Package / path:** Inline stroke SVGs in components (24px viewBox, stroke 2, round caps)
- **Notes:** The UI uses only a couple of icons, so no package. If the count grows past a handful, switch to Lucide and don't mix the two.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
